# Dataset placement

Download `creditcard.csv` from the original ULB Machine Learning Group dataset on Kaggle:

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Place it at `data/creditcard.csv` before running the script. The large third-party CSV is intentionally excluded from version control.

Expected columns: `Time`, `V1` through `V28`, `Amount`, and `Class` (0 for legitimate, 1 for fraud).
